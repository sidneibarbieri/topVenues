# Companion full-paper evaluation

The accepted full paper evaluated a different, frozen 9,925-record snapshot
with SHA-256 `0f4dbaa97d0cf39abd2340adb3280643df090b5de9cd1a29bff39a0b53ef64cd`.
It is not evidence for `security-20-v3`.

The immutable package contains the venue-stratified 200-record sample (seed
`20260721`), manual labels, source URLs and access dates, labeling instrument,
offline summarizer, live cross-index observations, and the protocol:

<https://github.com/sidneibarbieri/topVenues/tree/07674480ff3172f4b195387438ab3af3c9c5655f/evaluation/baseline_validation>

Its manual audit found 168 complete and uncontaminated abstracts among 200
labels (84.0%, exact 95% interval 78.2%-88.8%). This figure must remain bound
to that snapshot. A successor profile needs its own sampled labels before any
abstract-accuracy claim is made.
